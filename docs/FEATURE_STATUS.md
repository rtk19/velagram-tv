# Android TV feature status — 1.1.0

The TV interface and primary catalog/player workflow were rebuilt after reviewing the current iOS source. The UI is adapted to a remote and a landscape TV. This document separates implementation from validation; it does not certify universal format support or complete iOS equivalence.

| Area | Implemented in Android TV 1.1 | Evidence / remaining limits |
|---|---|---|
| Browsing and design | Cinematic backdrops, narrow icon rail, artwork shelves, poster grids, genre chips, focus animations, connection cards, right-side option panels | Captured from the installed release on a 1080p TV emulator; no design mockups substituted |
| TMDB catalog | Movies/series, trending/popular/top-rated/new releases, genre discovery, paginated search, title details, recommendations | Live TMDB calls and artwork verified with copied service configuration |
| Cast and people | Cast portraits/characters; clicking a person opens combined movie/series filmography; people appear in search | Captured with live TMDB data |
| Episodes | Season selector, still-image episode cards, runtime and synopsis; manual season/episode entry | Rendered and exercised in the emulator |
| Source discovery | Automatically combines connected Jellyfin/Emby, imported IPTV, Xtream VOD/series, Telegram, HTTP add-ons and enabled web providers; incremental provider status/results; cancellation when leaving | Jellyfin, Xtream and playlist integration fixtures pass on-device. Owner accounts remain untested |
| Matching | Metadata IDs first; year and season/episode validation; localized/original/translated title aliases; word boundaries prevent short-title false positives | JVM and on-device tests cover identity, wrong year/episode, translations and short names |
| Web providers | StreamingCommunity EN/Vixcloud, AnimeIL, HiAnime and Anikoto native protocol ports; encrypted-source extraction; provider subtitle tracks | iOS Nekostream and Megacloud fixtures pass. A live StreamingCommunity release was resolved in final QA; full provider availability and all current HTML contracts are not certified |
| Telegram login | Native TDLib; QR shown by default on TV, phone/code/password/email alternatives; local QR generation; encrypted database | Native runtime and actual QR-link response verified; owner has not signed in |
| Telegram discovery | Paginated account-wide video/document searches across chats, aliases and preferred English/Hebrew ordering | Uses server-side global search, removing the former 200-chat limitation from catalog discovery; real-account results still unverified |
| Telegram browser | Chats/folders/topics, search, pins, sort/filter, older-page video/document browsing | Main chat browser still initially shows 200 chats. Audio-only messages, invitation links and embedded text-media URLs do not yet match all iOS browser behavior |
| Playback UI | Shared custom controls for Media3 and VLC; timeline, elapsed/remaining time, media keys, D-pad seeking, speed/audio/subtitle/options sheets | Real MP4, MKV and AVI samples played in emulator; screenshots captured from both engines |
| Playback identity | Resume per episode; speed and zoom stored per catalog title, shared across its episodes/engines | Per-title speed tested on-device. Individual codec/DRM/4K/HDR/passthrough combinations require physical-device checks |
| Automatic engine | Prefer VLC for MKV/AVI in Automatic mode; Media3 for standard streams; decoder-error fallback to VLC | MKV/AVI selection and playback verified. VLC supports User-Agent/Referer; arbitrary authenticated headers remain more reliable in Media3 |
| Next episode | Source reuse preference, automatic source discovery, season rollover; bounded fallback to picker; predictive source/range preparation honoring Off/Wi-Fi/any-network policy | Season rollover tested on-device. Full authenticated next-episode playback/preloading still needs real-library testing |
| Subtitles | Embedded selection, local SRT/VTT, SubDL v2/Wizdom/Ktuvit/add-on search, primary/backup languages, provider switches, caption size/system settings; native subtitle Studio and saved timing versions | Timing, VTT separator preservation and latest-version preference tested. Online account/provider behavior unverified |
| Appearance/settings | All eleven iOS accent themes; default quality/speed, audio/anime/backup languages, subtitles on/off, search-language preference, provider choices, cache/retention | Settings are wired to the relevant clients/players. Touch double-tap is replaced by remote seeking; TV remains landscape. Some settings apply to Media3 rather than both engines |
| Library | Continue watching with artwork/progress, watchlist, watched history, downloads, per-profile libraries | Native persistence implemented; continue-watching populated through actual sample playback in QA |
| Live TV/radio | Original 84-entry directory and assets; alternates, Kan/Mako/HTML resolvers, search/groups/favorites/hiding/order; XMLTV now/next | Kan playback verified in earlier and current QA. Not every station is validated |
| IPTV | M3U URL/file import, header/metadata parsing, merging, guide discovery, Xtream live/VOD/series; catalog-source matching | Parsing and Xtream episode contract tests pass; owner provider accounts untested |
| Servers | Jellyfin/Emby sign-in, artwork browsing, folders/seasons/search, paginated matching, PlaybackInfo negotiation | On-device HTTP fixtures verify matching and token forwarding; owner servers untested |
| Profiles, storage, backups | Profiles, cache caps/retention, local files, HTTP file downloads/Telegram saves, versioned Android JSON backup/restore; server credentials sanitized from exported history | JSON backup is not an iOS-import format and does not embed downloaded/imported video bytes. Temporary-cache cap does not cover all TDLib storage |
| Background/PiP | Media3 foreground media service and optional PiP | No full VLC background/PiP counterpart; destruction of player activity ends the session |
| Casting/updates | Local TV playback and signed APK upgrades by ADB | AirPlay/Google Cast sender functionality and an in-app Android release updater are not included |

The iOS reference itself does not include torrent/debrid/AI speech engines. Those are not introduced here. Physical-TV installation remains deferred at the owner's request.
